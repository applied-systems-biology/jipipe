Prototype 02 rev 3 — Node relations panel

Cards render like real JIPipe nodes (taxonomy fill color, framework pattern, border) but without slots. The panel contributes exactly one factor: opacity. Current node 100%, related 60%, and the last visited nodes fade 85% → 65% over five steps back, after which they are indistinguishable from related nodes. Click a card to navigate.

Node relations
up / center / down
current (100%)   1 back (85%)   2 (80%)   3 (75%)   4 (70%)   5 (65%)   related (60%)
Fill/pattern/border are the node's own (demo uses the real taxonomy hues: Images 186°, Data sources 136°, Statistics 30°, Plotting 60°, Export ~160°, Scripting 300°). The trail ramp uses 5 equal 5% steps; older steps drop to the related level. The current node gets a 2px border in its own border color as the only extra cue - remove it if pure opacity is enough. +N collapses layers with more than 4 nodes.
